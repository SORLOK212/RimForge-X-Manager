## RimForge X Manager 1.0.0 — первый выпуск / first release

Бесплатный менеджер модов для RimWorld с открытым исходным кодом. Интерфейс на русском и английском.

### Что скачать
- **`RimForge-Setup-1.0.0.exe`** — установщик (рекомендуется). Права администратора не нужны.
- **`RimForge-1.0.0-portable.zip`** — портативная версия: распакуй и запусти `RimForge.exe`.

`RimForge.exe` и `latest.json` нужны для автообновления — скачивать их вручную не надо.

Windows 10/11 (64 бита). .NET устанавливать не нужно.

> Программа пока не подписана сертификатом. Если Windows покажет «Windows защитила ваш компьютер» —
> нажми **«Подробнее» → «Выполнить в любом случае»**. Контрольные суммы — в `SHA256SUMS.txt`.

### Возможности
- Поиск игры и модов, два списка с перетаскиванием, сборки со своими настройками модов
- «Светофор»: проверка зависимостей, несовместимостей, версий и порядка с исправлением одной кнопкой
- Умная сортировка, оценка времени запуска, разбор лога, конфликты модов и текстур, поиск мода-виновника
- Мастерская Steam и коллекции Steam прямо в программе, галерея картинок, скачивание с индикатором
- Копии игры с замороженными модами и скачивание других версий RimWorld через SteamCMD
- Перевод модов, помощник, MCP-сервер для ИИ-клиентов, автообновление

### What to download
- **`RimForge-Setup-1.0.0.exe`** — the installer (recommended), no administrator rights needed.
- **`RimForge-1.0.0-portable.zip`** — the portable build: unpack and run `RimForge.exe`.

`RimForge.exe` and `latest.json` are used by the built-in updater. Windows 10/11 x64, .NET bundled.
The app is not code-signed yet: if SmartScreen warns, choose *More info → Run anyway*.
