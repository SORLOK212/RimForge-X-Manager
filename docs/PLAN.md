# RimForge — план разработки

> **RimForge** — «кузница сборок». Бесплатный менеджер модов для RimWorld с открытым кодом.
> Цель: понятный любому игроку интерфейс, сортировка, которой можно доверять, и инструменты,
> которые экономят вечера на поиске сломанного мода.

---

## 1. Принципы

1. **Понятность важнее количества кнопок.** Каждая кнопка имеет подсказку простым языком с примером.
   По умолчанию включён «простой режим», сложные инструменты прячутся в «экспертный».
2. **Ничего не ломаем без возможности отката.** Перед любой записью в файлы игры делается резервная копия,
   у всех действий есть Ctrl+Z и история.
3. **Объясняем, а не просто делаем.** Сортировка говорит, *почему* мод стоит здесь; проверка говорит,
   *что* не так и *как* исправить одной кнопкой.
4. **Уважаем авторов модов.** Обмен сборками по умолчанию — через лёгкий файл (моды скачиваются из Мастерской).
   Полный архив — по выбору игрока, с предупреждением.
5. **Ядро отдельно от интерфейса.** Вся логика живёт в `RimForge.Core` — её используют и окно программы,
   и MCP-сервер для ИИ, и тесты.

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Платформа | Windows (код кроссплатформенный, Linux/Mac/Steam Deck — позже) |
| Языки интерфейса | Русский и английский; система локализации готова к добавлению других |
| Стек | C# / .NET 10, Avalonia UI 11.3, CommunityToolkit.Mvvm |
| Стиль | Тёмный современный, с мотивами игрового меню RimWorld (тёплые бежевые тексты, янтарный акцент, тонкие рамки панелей) |
| Версии игры | Steam и GOG, автоопределение путей при первом запуске; поддержка 1.6 (и 1.5 по версии из `Version.txt`) |
| Мастерская Steam | Steamworks API (менеджер подключается как RimWorld, appid 294100); SteamCMD — запасной путь для GOG |
| Обмен сборками | Два режима: лёгкий файл `.rimforge` и полный архив `.rimforge-full` |
| ИИ | На старте — только MCP-сервер. Встроенный чат — позже |

## 3. Архитектура

```
RimForge/
├─ src/
│  ├─ RimForge.Core/        Модели, чтение/запись файлов игры, сборки, сортировка, проверки
│  ├─ RimForge.Steam/       Мастерская: Steamworks-помощник, Web API, подборки, обновления
│  ├─ RimForge.Analysis/    Разбор логов, Harmony-анализ (Mono.Cecil), XML-конфликты      [этап 5]
│  ├─ RimForge.Mcp/         MCP-сервер для ИИ-ассистентов                                 [этап 6]
│  └─ RimForge.App/         Окно программы (Avalonia)
├─ companion/RimForgeCompanion/  Мод для RimWorld: замеры, живые ошибки, перезапуск       [этап 7]
├─ tests/RimForge.Core.Tests/
└─ docs/
```

### Где лежат данные

| Что | Где |
|---|---|
| Игра (Steam) | `<библиотека Steam>\steamapps\common\RimWorld` (библиотеки из `libraryfolders.vdf`) |
| Игра (GOG) | реестр `HKLM\SOFTWARE\WOW6432Node\GOG.com\Games\*` или выбор вручную |
| DLC и Core | `<игра>\Data\*` |
| Локальные моды | `<игра>\Mods\*` |
| Моды Мастерской | `<библиотека>\steamapps\workshop\content\294100\<id>` |
| Конфиг игры | `%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Config\ModsConfig.xml` |
| Сохранения | `...\Saves\*.rws` (в `<meta><modIds>` — список модов сейва) |
| Списки модов игры | `...\ModLists\*.rml` |
| Данные RimForge | `%APPDATA%\RimForge\` — настройки, сборки, кеш, резервные копии |

### Этап 1б — Удобство списка модов и перевод
- [x] **Метки «НОВЫЙ» и «ОБНОВЛЁН»**: новый — пока мод не включён и игра не запущена; обновлён — автор обновил после последней игры
- [x] **Категории по содержимому** (21: оружие, одежда, расы, постройки, интерфейс, производительность, библиотеки, патчи, переводы, жанры…):
      разбор Defs с учётом шаблонов-родителей, кеш по отпечатку папки; игрок может убрать/добавить категорию вручную
- [x] **Блок «Что внутри»** (оружие: 2 · гены: 9 …), размер мода на диске, «вес сборки» внизу окна
- [x] **Фильтры списков** (выпадающая панель): категории + состояние (новые, обновлённые, избранное, с проблемами,
      не для моей версии, удалены из Мастерской, есть в сохранениях, не используются)
- [x] Избранное (звёздочка) и заметки к модам
- [x] **Перевод описаний** на язык программы (названия модов не переводятся — по ним мод узнают и ищут):
      метка «EN → RU» с языком оригинала, «Показать оригинал», автоперевод при открытии мода, кеш переводов
- [x] **Два переводчика**: онлайн (Google) и встроенная модель NLLB-200 без интернета — скачивается по кнопке (~900 МБ,
      с продолжением после обрыва), «Удалить модель», выбор переводчика и запасной режим «если онлайн недоступен»
- [x] Встроенная модель ускорена: после загрузки декодер один раз перерабатывается (таблица словаря умножается в 8 битах,
      а не распаковывается в 1 ГБ на каждом слове) — описание за ~1 с вместо 15 с, память ~1,4 ГБ вместо 3,6 ГБ;
      предложения переводятся пачками; модель выгружается из памяти через 2 минуты без дела

### Этап 2 — Сортировка, которой можно доверять, и «светофор»
- [x] Базовый светофор уже работает (зависимости, несовместимость, версии, порядок, «нет на диске») с кнопками «Включить / Переставить / Найти / Убрать»
- [x] **Граф правил**: `About.xml` автора (зависимости, loadBefore/After, force*), база сообщества RimSort (скачивается с GitHub, кеш 3 дня), «обычные моды после игры и DLC»
- [x] Правила пользователя: правый клик по моду → «Всегда грузить после… / перед…» (выбор мода с поиском), видны и удаляются в «Почему он здесь?»
- [x] Уровни: «в самый верх / в самый низ» из базы сообщества; игра и DLC выше обычных модов
- [x] Сортировка с минимальными перестановками: два направления (опустить/поднять), выбирается вариант с меньшим числом сдвигов; правильный порядок не меняется
- [x] Противоречащие правила (циклы) находятся заранее и объясняются, такие моды остаются на месте
- [x] **Предпросмотр «было → станет»** перед применением, с причиной для каждого мода
- [x] **Два режима**: «Аккуратная» (минимум перестановок) и «Полная» (весь список по группам: выше игры → игра и DLC → библиотеки → моды → патчи → переводы, по алфавиту внутри групп)
- [x] Противоречия в описаниях модов показываются как пояснение и не красят светофор
- [x] **«Почему он здесь?»** — объяснение позиции каждого мода
- [x] «Закрепить вверху / внизу» (значок булавки; закреплённый мод стоит так высоко/низко, как позволяют зависимости); правила и закрепления
      хранятся в сборке, копируются при дублировании и попадают в файл `.rimforge`
- [x] **Предполётная проверка → светофор**:
  - нет зависимости (с кнопкой «Скачать» / «Найти в Мастерской» / «Включить»)
  - мод не поддерживает текущую версию игры; моды из списка «No Version Warning» (проверены сообществом) не предупреждают;
    мод для прошлой версии без своего кода — «скорее всего работает» (серым, для 1.7)
  - несовместимые моды (`incompatibleWith` + база сообщества)
  - дубликаты: мод включён дважды (локальный + Мастерская) → «Убрать копию»; один packageId в нескольких папках
  - нарушение порядка
  - нужен DLC, которого нет
- [x] Кнопка **«Исправить всё»**: список действий с галочками (включить, скачать, заменить заброшенные, убрать копии,
      расставить по порядку) + отдельный блок «Это нужно решить самому»; одно Ctrl+Z
- [x] База **«Используй вместо этого»** (Use This Instead от Mlie, MIT, ~2700 правил, кеш 3 дня): «Заменить» / «Скачать замену» —
      новый мод встаёт на место старого; при одинаковом ID — отписка от старого после загрузки
- [x] Описания установленных модов очищаются от BBCode и тегов `<color>` / `<b>`
- [x] База правил сообщества: лицензии нет, поэтому не входит в репозиторий — скачивается на ПК игрока с указанием источника

### Этап 3 — Steam Мастерская
- [x] Steamworks (Facepunch.Steamworks) в отдельном процессе-помощнике (`RimForge.exe --steam-helper`): подключается только когда нужно,
      сам закрывается через минуту без дела и перед кнопкой «Играть» — Steam не держит статус «играет в RimWorld»
- [x] Запасной путь без клиента Steam: официальный Web API (данные модов, коллекции) и страница Мастерской (поиск)
- [x] **Мастерская внутри программы**: поиск, сортировка (подходящие / популярное за неделю / подписчики / новые),
      «только для моей версии», «без переводов», карточки с картинками (кеш, уменьшенные превью), панель подробностей с описанием
- [x] Подписка/отписка, **очередь загрузок с прогрессом**; зависимости из About.xml скачанного мода докачиваются сами
- [x] После загрузки: пересканирование, включение в сборку (по галочке) и аккуратная сортировка
- [x] **Лента обновлений**: «обновились с прошлого раза» (по данным Steam на диске) + заметки автора («Что нового»),
      «ждут обновления» + «Обновить все», отметка «просмотрено»
- [x] Предупреждение о модах, удалённых из Мастерской
- [x] **Тематические подборки** (12 тем): несколько поисков → объединение, переводы и сценарии отсеиваются, уже установленные скрыты
- [x] **Скачать недостающие**: из светофора (моды сборки и зависимости), кнопки «Скачать» у проблем, «Найти» открывает поиск внутри программы
- [x] **Сборка из коллекции Steam** (ссылка → сводка «есть / скачать / размер / удалены» → новая сборка + загрузка)
- [x] **Фильтры Мастерской** (выпадающая панель): 20 категорий, «только моды», «скрыть установленные», «скрыть заброшенные»,
      сортировка «недавно обновлённые»; цветные подписчики / «нравится» / свежесть; галочка на уже установленных;
      пометка «нужен Biotech?» по описанию
- [x] **Чистка диска**: подписки, которых нет ни в одной сборке и ни в одном сохранении, — отписка с подтверждением
- [ ] Проверка подписки и загрузки на реальном аккаунте (ждёт разрешения игрока)
- [ ] SteamCMD для пользователей GOG
- [ ] «Скачать и включить» в карточках диагностики (недостающий шаблон/тип из модов, которых нет на диске)

### Этап 4 — Обмен сборками
- [x] **Файл `.rimforge`** (zip: `manifest.json` + по желанию настройки модов `settings/<мод>/<Класс>.xml`):
  - список модов с packageId, ID Мастерской, названием, датой обновления, размером
  - точный порядок загрузки, правила порядка сборки
  - версия игры и нужные DLC
  - описание для друга
  - кнопка «Поделиться» на карточке сборки → сохранение → папка с файлом открывается
- [x] **Полный архив** (тот же `.rimforge` + `mods/<мод>/…`): для друзей без Steam; игра и DLC не кладутся никогда;
      предупреждение о размере и правах авторов
- [x] **Открытие файла**: кнопка «Открыть файл сборки», перетаскивание в окно, путь в командной строке.
      Сводка: есть / скачать из Мастерской (~размер) / распаковать из файла / нет нигде / удалены из Мастерской /
      не хватает DLC / другая версия игры → «Создать сборку» → распаковка → точный порядок → настройки → загрузки
- [x] Предупреждение, если мод в Мастерской обновился после создания сборки
- [x] Настройки модов из сборки: старые — в резервную копию; для модов, которые ещё качаются, — после загрузки
- [x] **Переключение сборок вместе с настройками модов** (`profiles/<id>.settings`), не трогает игру, пока она запущена
- [x] **Библиотека RimForge и версии игры** (защита от обновлений, напр. RimWorld 1.7 на новом движке):
  - библиотека рядом с RimForge.exe (`Library\`; если папка только для чтения — `<диск>:\RimForge Library`)
  - «Сохранить копию этой версии»: игра без модов → `Games\<версия>`, сохранения и настройки → `Data\<версия>`,
    все моды → общее хранилище `Mods\<папка>@<отпечаток>` (одна версия мода хранится один раз для всех копий)
  - в папке `Mods` копии — только ссылки (junction, без прав администратора) → копия игры чистая, как в Mod Organizer
  - переключатель версии вверху окна; копия запускается напрямую с `-savedatafolder` (игра не перезапускает себя
    через Steam — проверено по коду игры: `RestartAppIfNecessary(AppId_t.Invalid)`)
  - моды, скачанные из Мастерской при выбранной копии, замораживаются в неё; удаление копии убирает и ненужные моды
  - сборки и их настройки модов хранятся отдельно для каждой версии игры
- [ ] Обновить замороженный мод в копии до текущей версии из Steam (по кнопке)
- [ ] Перенести локальные моды установленной игры в библиотеку (папка игры Steam тоже станет чистой)
- [ ] Получить другую версию игры: подсказка про бету «unstable» / ветки Steam, затем «Сохранить копию»
- [ ] Ассоциация файлов `.rimforge` (двойной клик) — вместе с установщиком (этап 8)

### Этап 5 — Диагностика: «найти виновника за полчаса, а не за вечер»

- [x] **XML-конфликты**: Replace/Remove одного и того же поля разными модами; перезапись одинаковых def (с учётом loadFolders.xml и папок версий)
- [x] **Поиск виновника делением пополам** (мастер в «Диагностике»):
  - [x] полуавтоматический: для ошибки из лога RimForge сам проверяет лог после запуска и подсказывает ответ
  - [ ] полностью автоматический: запуск с `-quicktest`, чтение лога, закрытие игры — без участия игрока
  - [x] ручной режим для багов геймплея: «проблема есть / нет», «Назад», «Прервать и вернуть сборку»

  - [ ] сначала проверять подозреваемых из анализа
- [x] **Автоисправления** (предпросмотр → одна кнопка → Ctrl+Z; файлы модов не меняются):
  - [x] включить установленный мод, где есть недостающий шаблон / тип / объект (с зависимостями)

## 6. Риски и как их закрываем

| Риск | Что делаем |
|---|---|
| Испортить `ModsConfig.xml` игрока | Резервная копия перед каждой записью, запись через временный файл |
| Steamworks показывает «играет в RimWorld» | Подключаемся только на время работы с Мастерской |
| Мастерская отдаёт только последнюю версию мода | Предупреждаем; для точной копии — полный архив или заморозка |
| Перезалив чужих модов в полном архиве | Режим по выбору, предупреждение, в файл пишутся авторы и ссылки |
| Статический анализ не находит все конфликты | Три линии защиты: проверка до запуска, разбор лога, поиск делением |
| Большие списки (800+ модов) тормозят | Виртуализация списков, кеш разобранных `About.xml` |
